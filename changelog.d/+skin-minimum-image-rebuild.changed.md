`SkinList` and `ReplicaList` on a fully periodic cell measure rebuild motion with minimum-image displacement (`Cell::dist2`), rebuild when the cell lattice changes (replacing the box-corner reuse allowance for periodic lists), unwrap boundary-crossing coordinates onto the reference or centroid image with checked `i32` wrap-shift arithmetic (`Error::Overflow`), reject non-finite coordinates with `Error::NonFinite` while leaving the previous list state and counters intact on any update error, and change `ReplicaList::sparsity` from `Vec<(u32, u32)>` to `Vec<(usize, usize)>` (breaking API change). `SkinList` with an open axis keeps raw displacement and the box-corner correction.
