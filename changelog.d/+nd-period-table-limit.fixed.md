- `lc_nd_build` names the period-table limit. A dimensionality whose optional-period table would not fit in `isize::MAX` bytes fails with `the period table does not fit in isize::MAX bytes` before any allocation. A dimensionality that passes that check fails with `the period table could not be allocated` when the allocator refuses the table. `n * d` that does not fit in `usize` fails with `n * d overflows` before the coordinates are read. `VpTreeIndex::new` returns `Overflow` (`n * k overflows`) for that product before it reads a point.
