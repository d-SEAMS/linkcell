`linkcell::Error` has one typeinfo. Its destructor is the key function, defined in `src/error.cpp` and linked as the shared library `linkcell_eh` (Meson `linkcell_dep`, CMake `linkcell::cpp` / `linkcell::eh`, pkg-config `-llinkcell_eh`). The library stays shared when linkcell is a Meson subproject or `default_library` is static, so a hidden-visibility consumer catches the exception by type. On Windows the class is `dllexport` in that library and `dllimport` in consumers. `eh_shared=false` and `LINKCELL_EH_STATIC=ON` link the object into each final image instead; that copy is unique only inside one final link.
