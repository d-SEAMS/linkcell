Meson finds libomp beside Clang's resource directory when the linker does not search that directory. Ubuntu's clang answers `-print-file-name=libomp.so` with the bare name and installs the library in `<llvm>/lib`, so `meson setup` with that clang stopped on "library 'omp' not found" even though `clang -fopenmp` links. `linkcell.pc` still names `-lomp` and records the directory it found.
