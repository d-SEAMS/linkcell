The cutoff search keeps its hits in one compact buffer, and each entry point writes its own layout from it once. `pairs_within_columns` returns the `i`, `j`, `S`, `dist2` columns; Python `linkcell.pairs_within` hands those to numpy without a copy. `lc_pairs_within` writes the caller's columns in parallel, and a count query keeps its search on the calling thread so the matching fill does not search again. `lc_pairs_within_rows` writes `lc_pair` rows, and the C++ `linkcell::pairs_within` fills its `ShiftedPair` vector with it.
