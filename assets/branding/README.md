# linkcell branding

The original mark for **linkcell** is a periodic linked-cell k-nearest neighbour search, in the same Library of Data Exchange (LODE) indigo / amber family as readcon-core, with a different geometry.

## Concept

- **Sheared parallelogram**: the cell is a general parallelepiped.
  An orthogonal dump box is a different shape.
- **Fractional bins**: the linked-cell mesh lives in fractional coordinates.
- **Four amber neighbours**: ice's `k = 4`; the k-heap, nearest first.
- **Gold wrap**: one neighbour sits across the periodic face.
  A unique-cell mark with one shift is the wrong picture; the walk visits the replica.
- **Pale source**: the query point in the primary cell.
- **Palette**: indigo / violet LODE-science (`#1E1B4B`, `#312E81`, `#4F46E5`) + amber (`#FBBF24`).
